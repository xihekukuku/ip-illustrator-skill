# 隐私、同意与许可

## 原始照片

- 原始真人照片只用于当前角色三视图生成，不复制、移动或长期保存。
- 不把原照片放进 IP 包、Skill 仓库、文章输出目录、示例或测试。
- 不在 manifest、角色规范、提示词、日志或最终报告中写入原照片绝对路径。
- 不保留 EXIF，不做人脸识别、实名识别，也不推断种族、健康、宗教、政治观点等敏感属性。
- 图像生成工具需要参考图时，只发送给用户当前选择的生成服务用于当次私有推理。

## 确认门

三视图是长期角色身份基线。创建正式包前必须让用户确认：

1. 三个视图是否是同一角色。
2. 发型、脸型、体型和年龄感是否正确。
3. 服装、配件、佩戴侧别和鞋型是否正确。
4. 哪些细节允许变化，哪些必须禁止漂移。

确认前只保留当次临时结果，不写正式包，也不开始批量文章配图。

## 权利与许可

- 只处理用户本人、有明确授权的人物，或用户有权使用的原创角色。
- 对第三方真人、受版权角色、品牌吉祥物和商业素材，要求用户确认有权创建和复用衍生形象。
- 自定义 IP 包默认 `license: private`。
- 只有用户明确提供许可名称与必要署名时，才写入其他许可和 attribution。
- 仓库的 MIT License 只覆盖 Skill 的代码和文档，不覆盖用户输入、用户 IP 包或生成图片。

## 数据边界

Skill 卸载不自动删除 `~/.agents/personal-ip-article-illustrations/` 中的用户 IP。删除用户数据属于独立操作，必须由用户明确要求并精确确认目标。
