# 三视图工作流

## 输入

优先使用：

- 一张清晰、无遮挡、可辨认发型、脸型、体型和主要服装的人物照片；或
- 一张已经完成的角色正面、侧面、背面三视图。

照片信息不足时先说明缺口，不发明固定身份特征。

## 必须确认的信息

1. IP 显示名称和角色气质。
2. 固定发型、脸型、年龄感、体型和头身比。
3. 标志性服装、稳定配色和鞋型。
4. 固定配件、形状、材质与准确佩戴侧别。
5. 允许随场景变化的部分。
6. 明确禁止出现的身份和风格漂移。

## 生成要求

- 一张横版白底画布依次展示同一角色的正面、标准侧面和背面。
- 三个全身视图完整不裁切、自然直立、相同高度、相同地面线。
- 年龄、脸型、发型、肤色、体型、头身比和四肢长度一致。
- 侧面清楚显示鼻、下巴、后脑、服装侧面和鞋型。
- 背面清楚显示发型后部、服装后部、配件后部和鞋跟。
- 固定配件在可见角度保持同一身体侧别、形状和材质。
- 不加入道具、场景、标题、边框、阴影人物或额外角色。
- 默认使用彩色半写实 2D 漫画语言：清晰结构、轻手绘轮廓、克制明暗。

## 提示词骨架

> 创建一张专业角色三视图，横版纯白背景。依次展示同一角色的正面、标准侧面和背面，全身完整、不裁切、相同高度、相同地面线、自然直立中性姿势。角色定位为[定位与气质]，固定身份特征为[发型、脸型、年龄感、肤色、体型、头身比]，穿[标志性服装与稳定配色]，佩戴[固定配件及准确身体侧别]。三个视图必须保持同一身份、身体比例、服装结构、配件侧别和鞋型。彩色半写实 2D 漫画质感，轻手绘轮廓、克制明暗、结构清晰。不要加入场景、道具、标题、额外角色。禁止[禁止特征]。输入真人照片只作当次身份参考，不进入输出或角色包。

工具支持参考图时直接传入参考图，不只依赖文字复述。

## 检查与确认

- 是否只有同一角色的三个角度。
- 三视图比例、发型轮廓、肤色和脸部结构是否稳定。
- 服装版型、主色、纹样、鞋型和配件侧别是否一致。
- 是否因美化改变了年龄、体型或身份。
- 是否没有额外道具、文字、场景和人物。

每次修订只处理一个主要问题。用户确认后再创建正式 IP 包。
