# Example Creator 角色规范

## 角色定位
- 冷静、可信、善于把复杂关系拆清楚的创作者。

## 固定身份特征
- 深色短发，清晰脸型，中性成年体型，约七头身。

## 标志性服装与配件
- 深灰短外套、浅色内搭、直筒长裤和白色低帮鞋。
- 右手佩戴一枚窄幅深色腕带。

## 允许变化
- 表情、动作、坐姿、站姿与不改变身份的季节性外层服装。

## 禁止漂移
- 不改变发型轮廓、身体比例、腕带侧别和鞋型。
- 不转为写实照片、3D 塑料人物或儿童比例。

## 生图提示词片段
同一名成年创作者，深色短发，清晰脸型，中性七头身，深灰短外套、浅色内搭、直筒长裤、白色低帮鞋，角色右手窄幅深色腕带。

## 一致性检查清单
- [ ] 脸型、发型和年龄感一致
- [ ] 身体比例一致
- [ ] 服装结构与稳定色一致
- [ ] 右手腕带的侧别、形状与材质一致
- [ ] 白色低帮鞋型一致
