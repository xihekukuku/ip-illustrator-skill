# Example IP 角色规范

## 角色定位
- 替换为用户确认的角色气质与叙事作用。

## 固定身份特征
- 替换为用户确认的发型、脸型、年龄感、肤色、体型和头身比。

## 标志性服装与配件
- 替换为服装版型、稳定颜色、鞋型、配件形状与准确身体侧别。

## 允许变化
- 表情、动作和不影响身份的场景适配元素。

## 禁止漂移
- 替换为禁止出现或改变的身份特征。

## 生图提示词片段
替换为不含本机路径、可独立复用的角色身份描述。

## 一致性检查清单
- [ ] 脸型、发型和年龄感一致
- [ ] 身体比例一致
- [ ] 服装结构与稳定色一致
- [ ] 固定配件侧别、形状与材质一致
- [ ] 鞋型一致
