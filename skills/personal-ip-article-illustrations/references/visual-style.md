# 白底留白水彩隐喻插图规范

## 定位

为文章、帖子和观点制作简洁的杂志专栏概念插图。当前个人 IP 是现实锚点；少量日常物件之间安静、不可能但逻辑准确的关系，承担文章隐喻。

## 内容优先级

1. 文章核心观点。
2. 承载观点的单一异常关系。
3. 必要物件与少量准确短文字。
4. 当前 IP 的动作、情绪和叙事职责。

角色参与并触发关系，但不压过观点。

## 画面语言

- 16:9 横版文章正文插图。
- 纯白背景，大面积留白，整体简洁。
- 完整彩色、低饱和水彩漫画质感；轻纸张颗粒、薄涂、细铅笔或墨线轮廓、克制明暗。
- 使用有限协调色彩；角色稳定色只作点缀。
- 每张图一个超现实关系和 1—3 个主要物件。
- 第一眼看懂人物与物件的深层关系，第二眼发现一个不太合理、却准确回应文章观点的细节。
- 允许比例、空间、影子、方向和连接关系脱离现实逻辑。
- 气质成熟、安静、克制，可带轻微冷幽默。

## 当前 IP

- 三视图中的三个形象是同一角色的不同角度。
- 保持包内身体比例、脸型、发型、服装、配件侧别、鞋型和稳定配色。
- 默认单个人物占画布约 10%—20%。
- 可让同一 IP 的 1—4 个分身表示阶段、重复、对照、选择或内心冲突；所有分身仍保持辅助占比。
- 表情、头部角度、动作和情绪可随文章变化，固定身份不可漂移。

## 文字

- 使用文章主要语言。
- 默认 0—3 处短文字；中文每处尽量 2—8 个字。
- 文字作为标签、批注或物件内容参与关系，不复述整段文章。
- 生成前列出必须逐字准确呈现的文字；不确定时宁可少字。

## 避免

- 封面、商业海报、PPT、流程图、卡片式信息图。
- 摄影写实、完整复杂场景、电影光影、3D 渲染和塑料质感。
- 多个竞争隐喻、复杂机械、怪物、图标堆叠和装饰过载。
- 大段解释文字、无关标题和重复标签。
- 把人物放大成广告主角，或让人物随场景变成另一角色。
