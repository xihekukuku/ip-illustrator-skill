# 角色规范模板

角色规范只记录用户确认且可观察、可执行的视觉规则，不写私人背景、原始照片路径或未确认推断。

```markdown
# <显示名称> 角色规范

## 角色定位
- <角色气质与叙事作用>

## 固定身份特征
- <发型、脸型、年龄感、肤色、体型、头身比>

## 标志性服装与配件
- <服装版型、稳定颜色、鞋型>
- <配件形状、材质、准确身体侧别>

## 允许变化
- <表情、动作、场景适配服装等>

## 禁止漂移
- <绝不能改变或出现的特征>

## 生图提示词片段
<一段独立可复用的角色身份描述，不含本机路径>

## 一致性检查清单
- [ ] 脸型、发型和年龄感一致
- [ ] 身体比例一致
- [ ] 服装结构与稳定色一致
- [ ] 固定配件侧别、形状与材质一致
- [ ] 鞋型一致
```
